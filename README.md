# Holidays Tracker Frontend

Aplicación frontend creada con Angular 22.

## Requisitos

- Node.js compatible con Angular CLI 22
- npm

## Desarrollo local

Instala las dependencias y levanta la aplicación con Angular CLI:

```bash
npm install
npm start
```

La aplicación estará disponible en `http://localhost:4200/` y consumirá la API en `http://localhost:8080/` mediante la configuración `development` de Angular. El backend debe estar levantado en ese puerto y permitir CORS desde `http://localhost:4200`.

## Compilación

```bash
npm run build
```
